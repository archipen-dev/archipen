# Controls

Archipen uses Figma-style controls. Press `?` in the editor for the full list.

The keys are written Mac-style below. On Windows and Linux, use `Ctrl` for `⌘`, `Shift` for `⇧` and `Alt` for `⌥`. The
editor itself shows the right keys for your system.

| | |
|---|---|
| Pan | `Space`+drag, middle mouse, scroll, or `H` |
| Zoom | `Ctrl/⌘`+scroll, pinch, `⌘+` / `⌘−` |
| Fit, selection, 100% | `Shift+1`, `Shift+2`, `Shift+0` |
| Projection | `Shift+P` switches between isometric and 2D |
| Tools | `V` select, `R` node, `F` zone, `C` connect, `T` text, `N` note |
| Edit | `Enter` rename, `⌘D` duplicate, `Alt`+drag duplicate, arrows nudge (screen-relative in iso), `⌘Z` undo |
| Lock, hide | `⇧⌘L` lock or unlock, `⇧⌘H` hide or show the selection |
| Pages | Click a linked node or zone in a shared diagram or present mode to open its page; `⌘Enter` (or `Enter` in a shared diagram) on the selected one. `⌥←` goes back (`⌫` in a shared diagram). |
| Present | `P` full screen, `Esc` to exit |
| Files | `⌘S` save, `⇧⌘S` save as, `⌘O` open |

Drop an SVG file on the canvas to use it as a custom icon.
